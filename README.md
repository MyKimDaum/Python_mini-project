## 미니 프로젝트 - 쇼핑몰 장바구니 미니 프로젝트

### 실행 방법
터미널에서 shop.py 파일이 있는 폴더로 이동한 뒤 실행합니다.
```bash
python shop.py
```

### 기능 소개
- **1. 상품 목록 :** 상품 번호, 이름, 가격, 현재 재고 표시(0개는 품절)
- **2. 담기:** 상품 번호와 수량 입력, 재고 확인 후 장바구니에 추가
- **3. 빼기:** 선택한 상품을 장바구니에서 전체 제거
- **4. 장바구니:** 상품별 가격, 상품 합계, 할인, 배송비, 최종 금액 출력
- **5. 쿠폰:** 쿠폰 없음 / 10% 할인(최대 5,000원) / 20,000원 이상 구매시 3,000원 할인
- **6. 결제:** 재고 확인 후 영수증 출력, 상품 재고 차감, 장바구니 및 쿠폰 초기화
- **q. 종료**

배송비는 **할인 적용 후 금액이 30,000원 이상이면 무료**, 그 미만이면 3,000원

### 주요 클래스
- 'Product': 상품 정보와 재고 감소 처리
- 'Cart': 상품 추가/삭제/합계/계산/초기화
- 'Discount', 'RateDiscount', 'FixedDiscount': 상속 및 오버라이딩을 통한 쿠폰 계산

### 테스트 예시
1. 메뉴에서 '2'를 선택하고 상품 번호 '2'(텀블러)를 2개 담는다.
2. 메뉴 '5'에서 '2'를 선택해 10% 할인 쿠폰을 적용한다.
3. 메뉴 '4'에서 합계 30,000원, 할인 3,000원, 배송비 3,000원, 결제금액 30,000원을 확인한다.
3. 메뉴 '6'을 눌러 결제한 후 메뉴 '1'에서 텀블러 재고가 10개에서 8개로 감소했는지 확인한다.


### 참고
- 3.빼기 출력 / 4.장바구니 출력 / 6.결제 출력은 시간상의 문제로 구현하지 못함
- 실행 화면에서 타이틀 출력 / 1.상품 목록 출력 / 2.담기 선택시 상품 번호 입력 가능, 수량 또한 입력 가능함
- 5.쿠폰 출력 가능
- 5.쿠폰 선택시 쿠폰 번호 입력 가능하며 해당되는 쿠폰이 적용되었다는 메시지 뜨도록 함, 쿠폰 번호 1 입력시 적용할 쿠폰이 없다고 별도로 안내
- 위에 언급한 구현 가능한 것(1, 2, 5번)은 오류 없도록 설계함 (제시된 번호 이외의 숫자 입력 또는 문자 입력시 별도의 메시지 삽입)
